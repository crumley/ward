# Glossary

> **Layer:** intent · foundation (global). Shared vocabulary. **Status:** placeholder skeleton.

A quick-reference table for Ward's vocabulary. Each term gives a one-line meaning and points to the
**slice that defines it authoritatively** (the _one home_ per the rules in `../README.md`). The
glossary never becomes a second definition — it indexes, it does not own.

## Planned form

A table: **Term | One-line meaning | Defining slice**. Each term points to the slice that defines it
authoritatively, e.g.:

- Workspace, Project, Floor, Task, Worktree, Room, Repository, Main line, Status (derived) →
  `concepts/work-hierarchy.md`
- Identity (slug + code), floor/room codes → `concepts/identity.md`
- Scope, Working directory, Agent, Persona, the role cast, Teaching loop, Dispatch, Report, Wake,
  Fork → `concepts/roles.md`
- Session, Open vs. running, lifecycle ops, Harness handle, Context loading, Recovery →
  `concepts/sessions.md`
- Artifact, Provenance, Brief → `concepts/artifacts.md`
- Local↔remote boundary, never-merge-to-main, Refresh, Rebase, Lifecycle hooks, Workflow policy,
  Gated action → `concepts/delivery.md`
- Reflection, Reflection cursor, Update vs. migrate, Reconciliation → `concepts/reflection.md`
- Seam, and each subsystem name → `subsystems/*.md`
